3. **AI エージェント用のファイル：** エージェントへの指示が書かれ、すべて同じ内容で、非公開リポジトリへ案内します：`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`.github/copilot-instructions.md`。
4. `CNAME`：独自ドメイン（`senajg.com`）。
5. `.nojekyll`：ファイルをそのままの形で公開します。
6. `.gitattributes`：ファイルに関する Git のルール（改行コードと、画像をバイナリとして扱うこと）。
7. `robots.txt`：検索エンジンがこのドメインで読む唯一の `robots.txt` です。サイトマップの場所を示します。
8. `sitemap.xml`：ウェブサイトのすべてのページと、rev.82 からは README のページを載せた、一つだけのサイトマップ。
9. `404.html`：エラーページで、ホームページへのボタンがあります。
10. `favicon.ico`：ブラウザーのタブのアイコン（青いマンダラ、16、32、48 px）。
11. `apple-touch-icon.png`：iPhone や iPad のホーム画面にウェブサイトを追加する人のための、180×180 のアイコン。
12. `assets/`：カードの表紙とメインページのアイコン。ほかに次のものがあります：
    1. `aco-escovado.js`：回転する金属のボタン
    2. `seta-voltar.js`：「戻る」ボタンの回転する矢印
    3. Kindle ボタンの街の鏡の写真：`mirror-city.webp` と `mirror-eagle.webp`
    4. Reality のページの背景：`fundo-bolhas.js`（入れ替わる泡宇宙の画像、`universo-bolha-1.webp` から `universo-bolha-4.webp` まで）と `cubos-metal.webp`（金属の立方体）
